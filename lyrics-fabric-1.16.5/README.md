# Lyrics (Fabric 1.16.5)

Клиентский мод: показывает, что играет на ПК, и синхронизированный текст песни (LRCLIB) прямо в Minecraft.

## Сборка
Нужен JDK 17 (или 8/11/16). Один раз:

    gradle wrapper --gradle-version 7.3.3     # если нет ./gradlew
    ./gradlew build                           # Windows: gradlew.bat build

Готовый jar: `build/libs/lyrics-fabric-1.0.0.jar` → в `.minecraft/mods`
(нужны Fabric Loader >= 0.11 и Fabric API 0.42.0+1.16).
Можно также открыть папку в IntelliJ IDEA как Gradle-проект и запустить `runClient`.

## Что умеет
- Строки текста в реальном времени, 3 стиля: BORDERLESS / BORDERED / COMPACT
- 3D-текст: плавающие в мире строки, повёрнутые к камере
- Режим элитр: при полёте 3D-текст выносится далеко вперёд
- Экран настроек (кнопка Down): HUD, стиль, позиция, строки, масштаб, тост, 3D, элитры, сдвиг синхронизации
- Тост «сейчас играет» (название, артист, прогресс) при смене трека
- Если текста нет — показывается название и артист
- Windows: Spotify, Apple Music, YouTube Music, браузеры (через системную медиа-сессию)
- Linux: любой MPRIS-плеер (нужен `playerctl`); macOS: Spotify и Music

## Клавиши (меняются в Управление → Lyrics)
| Клавиша | Действие |
|---|---|
| Up | показать/скрыть HUD |
| Down | открыть экран настроек |
| Left / Right | предыдущий / следующий трек |
| Ctrl+Left / Ctrl+Right | сдвиг синхронизации -/+250 мс |
| End | пауза / воспроизведение |

Настройки: экран настроек или `config/lyrics.json`.

Подробно про установку всех нужных модов: `INSTALL_ru.md`.
